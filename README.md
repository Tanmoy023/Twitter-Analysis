# 🐦 Twitter Analysis Dashboard – Power BI Project

## 📊 Overview
The **Twitter Analysis Dashboard** is an end-to-end data visualization project built using **Power BI**.  
It transforms raw Twitter data into meaningful insights to help analyze engagement trends and user interactions over time.  
The main goal of this project is to demonstrate how **ETL (Extract, Transform, Load)** and **data storytelling** can empower data-driven decision-making.

---

## ⚙️ ETL Process
- **Extracted** raw tweet data including tweet count, likes, retweets, URL clicks, and media engagements.  
- **Transformed** data using **Power Query** by cleaning, formatting, and deriving new metrics such as engagement rate and total interactions.  
- **Loaded** the cleaned dataset into Power BI to build data models and create interactive visualizations.

---

## 📈 Dashboard Features
- Interactive **month selector** to analyze engagement trends dynamically.  
- Displays key performance metrics like:  
  - Tweet count and total tweets  
  - Likes, retweets, URL clicks  
  - Media views and media engagements  
  - Average engagement rate  
- Includes **trend analysis charts**, KPIs, and filters for deeper insight.  
- Visually appealing design for storytelling and presentation.
